<h2 style="margin: 34px 0 12px; color: #1f4e78; font-size: 24px; border-bottom: 2px solid #1f4e78; padding-bottom: 6px;">1. Objective</h2>
<p style="margin: 0 0 16px;">This document contains a detailed description of the Basic Zybo Z7-10 System Configuration used for teaching in the IEE 5002E Programmable Systems course delivered at USFQ.</p>
<h2 style="margin: 34px 0 12px; color: #1f4e78; font-size: 24px; border-bottom: 2px solid #1f4e78; padding-bottom: 6px;">2. Scope</h2>
<p style="margin: 0 0 16px;">The descriptions provided in this document are relevant to the XSA file provided to students. If students need to modify or access the configuration for real-time hardware debugging, they can follow the steps in the GitHub and Project Restoring section.</p>
<p style="margin: 0 0 16px;">This document also links to the relevant class examples to be used in Vitis 2025.2.</p>

<h2 style="margin: 34px 0 12px; color: #1f4e78; font-size: 24px; border-bottom: 2px solid #1f4e78; padding-bottom: 6px;">8. GitHub and Project Restoring</h2>
<p style="margin: 0 0 10px;"><strong>The Tcl scripts were generated using the following command in the Vivado Tcl console:</strong></p>
<pre style="margin: 0 0 20px; padding: 14px; background-color: #1f2937; color: #f9fafb; border-radius: 4px; overflow-x: auto; white-space: pre-wrap; font-family: Consolas,'Courier New',monospace; font-size: 14px; line-height: 1.45;"># Export Project Tcl
write_project_tcl -force ./scripts/build_project.tcl<br>write_bd_tcl -force ./scripts/build_bd.tcl</pre>
<p style="margin: 0 0 10px;"><strong>To clone the project on your local computer:</strong></p>
<p style="margin: 0 0 10px;">Create and navigate to an empty directory in your home directory:</p>
<pre style="margin: 0 0 20px; padding: 14px; background-color: #1f2937; color: #f9fafb; border-radius: 4px; overflow-x: auto; white-space: pre-wrap; font-family: Consolas,'Courier New',monospace; font-size: 14px; line-height: 1.45;">mkdir ~/progsystems/&lt;folder&gt;
cd ~/progsystems/&lt;folder&gt;</pre>
<p style="margin: 0 0 10px;">Clone the repository:</p>
<pre style="margin: 0 0 20px; padding: 14px; background-color: #1f2937; color: #f9fafb; border-radius: 4px; overflow-x: auto; white-space: pre-wrap; font-family: Consolas,'Courier New',monospace; font-size: 14px; line-height: 1.45;">git clone https://github.com/aesanchezteran/TeachingSystem.git</pre>
<p style="margin: 0 0 10px;"><strong>To recreate the Vivado project from the hardware folder:</strong></p>
<pre style="margin: 0 0 20px; padding: 14px; background-color: #1f2937; color: #f9fafb; border-radius: 4px; overflow-x: auto; white-space: pre-wrap; font-family: Consolas,'Courier New',monospace; font-size: 14px; line-height: 1.45;"># Recreate project settings, constraints, and HDL sources
vivado -mode batch -source ./scripts/build.tcl</pre>
<p style="margin: 0 0 16px;">Your project should now be ready to view and modify. You can examine it by launching Vivado and opening the project.</p>
